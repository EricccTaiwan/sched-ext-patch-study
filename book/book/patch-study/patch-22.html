Patch 22: sched_ext: Implement SCX_KICK_WAIT

View on Lore: https://lore.kernel.org/all/20240618212056.2833381-23-tj@kernel.org

Commit Message

From: David Vernet dvernet@meta.com

If set when calling scx_bpf_kick_cpu(), the invoking CPU will busy wait for the kicked cpu to enter the scheduler. See the following for example usage:

https://github.com/sched-ext/scx/blob/main/scheds/c/scx_pair.bpf.c

- Include SCX_KICK_WAIT related information in debug dump.
