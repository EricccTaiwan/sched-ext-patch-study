sched_ext Patch Series Study

Patch 07: sched: Add normal_policy()

View on Lore: https://lore.kernel.org/all/20240618212056.2833381-8-tj@kernel.org

Commit Message

A new BPF extensible sched_class will need to dynamically change how a task picks its sched_class. For example, if the loaded BPF scheduler progs fail, the tasks will be forced back on CFS even if the task's policy is set to the new sched_class. To support such mapping, add normal_policy() which wraps testing for %SCHED_NORMAL. This doesn't cause any behavior changes.
